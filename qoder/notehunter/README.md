# 📚 笔记猎人 NoteHunter

> 基于 OceanBase seekdb 的本地学习资料语义检索助手

## 项目简介

学生在复习时，常常在几十份课程笔记、实验记录、PDF 里找不到某个知识点——记不住它在哪份文件里，关键词搜索也常常对不上表述。

**笔记猎人**把本地文档自动切片后存入 seekdb 向量数据库，让你用一句自然语言就能找到原文段落和出处，不再为"那个知识点在哪"而焦虑。

## 核心特性

- **语义检索**：用自然语言提问，基于向量相似度找到最相关的笔记段落
- **混合检索**：支持限定文件名过滤，在指定文档中精确搜索
- **自动切片**：智能按段落切分文档，保留来源信息
- **多格式支持**：`.md` / `.txt` / `.pdf` 三种常见格式
- **零部署**：seekdb 嵌入式模式，无需安装数据库服务或 Docker

## 技术栈

| 组件 | 技术 |
|------|------|
| 向量数据库 | pyseekdb（嵌入式模式） |
| Web 框架 | Flask |
| 前端 | 原生 HTML + CSS + JavaScript |
| PDF 解析 | pypdf |
| Python 版本 | 3.11+ |

## 目录结构

```
notehunter/
├── app.py            # Flask 主程序（Web 服务入口）

```

## 安装依赖

```bash
# 1. 进入项目目录
cd notehunter

# 2. （推荐）创建并激活虚拟环境
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

pip install -r requirements.txt
```

> **提示**：首次运行检索时，pyseekdb 会自动下载 embedding 模型（约几百 MB），属正常现象，请耐心等待。

## 使用流程

### 第一步：准备文档

把你要检索的笔记文件（`.md` / `.txt` / `.pdf`）放到 `data/` 目录下。

项目已自带 3 份示例文档用于演示：
- `数据结构笔记.md` —— 计算机数据结构课程笔记
- `操作系统要点.md` —— 操作系统核心知识点
- `计算机网络整理.md` —— 计算机网络复习笔记

### 第二步：启动 Web 服务

```bash
python app.py
```

启动后在浏览器打开：**http://127.0.0.1:5000**

### 第三步：导入文档

在网页上点击 **「📥 导入 data/ 目录文档」** 按钮，等待提示"导入完成"。

> 如果之前导入过，想重新来，先点 **「🗑️ 重置数据库」** 清空数据，再重新导入。

### 第四步：开始搜索

1. 在 **搜索内容** 框里输入你的问题，例如：
   - "什么是二叉树的遍历？"
   - "进程调度算法有哪些？"
   - "TCP 三次握手的过程"
2. （可选）在 **限定文件名** 框里输入文件名，只在某份文档中搜索
3. 点击 **「🔍 开始搜索」** 或按回车

### 第五步：查看结果

每条结果展示：
- **原文片段**：匹配到的笔记段落
- **来源文件名**：这段内容出自哪个文件
- **段落序号**：在原文中的段落编号
- **相似度距离**：数值越小表示越相关

## 命令行单独导入（可选）

如果不想通过网页，也可以直接在命令行执行导入：

```bash
python ingest.py
```

这会自动扫描 `data/` 目录下的所有支持文件并写入 seekdb。

## 常见问题

**Q: 搜索没有结果？**
- 确认已经点击"导入"按钮完成文档导入
- 首次运行需要下载 embedding 模型，请检查网络

**Q: 想更换文档集合？**
- 先点"重置数据库"，把新文件放到 `data/` 目录，再重新导入

**Q: 重复导入后结果重复？**
- 每次导入前请先重置数据库，避免数据重复
